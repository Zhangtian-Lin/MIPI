# 身份权限与数据访问矩阵

> 版本：v1.0-draft

## 1. 角色

`anonymous`、`user`、`researcher`、`reviewer`、`senior_reviewer`、`publisher`、`source_admin`、`data_steward`、`system_admin`、`crawl_agent`、`processing_agent`、`web_agent`。

## 2. 权限矩阵

| 动作 | 公开用户 | Reviewer | Publisher | Data Steward | Crawl Agent | Processing Agent | Admin |
|---|---:|---:|---:|---:|---:|---:|---:|
| 查看 L4 | 是 | 是 | 是 | 是 | 否 | 否 | 是 |
| 查看 L2 | 否 | 是 | 是 | 是 | 自产物 | 是 | 是 |
| 查看隔离区 | 否 | 否 | 否 | 条件 | 否 | 否 | 条件 |

## 3. 规则

- 默认拒绝；
- 权限按最小范围和最短时间授予；
- 生产权限与测试权限分离；
- 高风险操作需要重新认证和审计；
- Agent 身份不能模拟人工审核员；
- 删除、隔离释放、批量导出和权限修改需要双人批准；
- 每 90 天复核长期权限。

## 4. 审计字段

主体、角色、动作、对象、前后值、理由、任务、IP/客户端、时间、批准人和结果。审计日志不可由普通业务角色修改。
