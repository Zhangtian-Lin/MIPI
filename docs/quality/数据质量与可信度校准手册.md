# 数据质量与可信度校准手册

> 版本：v1.0-draft

## 1. 质量维度

完整性、准确性、一致性、及时性、唯一性、可追溯性和有效性分别计量，不合并成单一模糊总分。

## 2. S 等级校准

评估来源身份、对该事实类型的法定或第一方地位、原始报道能力、署名、更正机制、转载依赖和历史准确性。域名或机构级默认值允许文档级覆盖。

## 3. F 等级升级

- F0→F1：至少一个可识别来源；
- F1→F2：事实类型对应的第一方正式披露；
- F2→F3：存在至少两个真正独立来源，关键字段一致；
- →F4：命中该事实类型认可的法定或主管记录。

任何升级都以 Claim 为单位，不以整篇文档或整个事件统一提升。

## 4. 硬校验

- 金额：币种、数量级、计划/批准/投入口径；
- 日期：发布、事件、生效、抓取分别处理；
- 项目状态：必须有状态依据；
- 政策：宣布、公布、生效、废止分开；
- 选举：非正式计票不能作为最终结果；
- 独立性：转载不能重复加权。

## 5. 抽样

R0 自动结果按风险分层抽样；新来源、新语言、新模型和新分类提高抽样比例。发现 blocker 时暂停相同批次，扩大复核并完成根因分析。

## 6. 冲突

保留所有口径和证据，指定 `current_selected_value`、选择理由、适用时间和冲突状态。不得为保持页面整洁而删除可靠冲突来源。
