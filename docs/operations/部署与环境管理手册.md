# 部署与环境管理手册

> 版本：v1.0-draft

## 1. 环境

`local`、`test`、`staging`、`production` 使用独立数据库、对象存储、队列、密钥和第三方模型配置。非生产页面必须显著标识。

## 2. 发布前检查

- 契约和数据库迁移兼容；
- 格式、类型、单元、契约、集成和关键 E2E 通过；
- 安全与提示注入回归通过；
- 备份有效且回滚包已生成；
- 环境变量完整但不输出值；
- 变更记录、负责人和观察窗口明确。

## 3. 发布顺序

备份 → 执行向后兼容迁移 → 部署 Worker/API → 健康检查 → 部署 Web → 冒烟测试 → 开启流量 → 观察指标 → 完成或回滚。

破坏性数据库变更使用 expand/migrate/contract，多版本共存期间禁止提前删除旧字段。

## 4. 回滚

应用回滚与数据回滚分开。优先回滚代码并停止新写入；数据库不可逆迁移必须有前向修复方案。回滚后验证首页、API、队列、证据和审核功能。

## 5. 权限

生产部署、DNS、域名、第三方账户和真实通知需要明确授权。CI 账号使用最小权限和短期凭证。

## 6. 发布记录

版本、提交、契约、迁移、模型、提示词、时间、执行人、批准人、测试、监控链接、问题和回滚状态。
