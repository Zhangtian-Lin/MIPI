# 人工审核、发布与更正 SOP

> 版本：v1.0-draft

## 1. 角色

- Reviewer：核对原文、字段、实体和冲突；
- Senior Reviewer：处理政策、政治、重大金额和复杂冲突；
- Publisher：批准公开投影；
- Data Steward：批准实体合并、分类和历史更正；
- Security/Compliance：处理隔离内容、隐私和版权。

同一高风险内容的提取者不能成为唯一批准者。

## 2. 审核等级

| 风险 | 示例 | 要求 |
|---|---|---|
| R0 | 低风险已知格式 | 自动校验，可抽样 |
| R1 | 普通企业公告 | 一人审核 |
| R2 | 重大投资、政策条件、项目取消 | 一名 Reviewer + 一名 Senior Reviewer |
| R3 | 正式选举、争议指控、法律效力、敏感更正 | 双人审核并由 Publisher 批准 |

## 3. 审核清单

- 来源身份与 S 等级是否匹配；
- 原文版本、日期和 source span；
- 金额、币种、条件、否定和未来时态；
- 企业、项目、政策和地理实体是否正确；
- 是否为转载或同一 independence group；
- F 等级是否有足够依据；
- 冲突是否完整呈现；
- 是否涉及隐私、版权、诽谤或安全风险；
- 页面标题是否超出证据。

## 4. 发布决策

结果为 `approve`、`approve_with_limits`、`return_for_fix`、`reject`、`quarantine`。决定必须包含理由、审核人、时间和规则版本。

F0 默认不公开；F1 仅以明确“单一来源报道”展示；R2/R3 不允许全自动发布。

## 5. 更正与撤回

发现错误后：冻结相关投影 → 确定受影响 Claim/Event/Page/Answer → 保存旧版本 → 发布更正 → 重新计算统计和搜索 → 通知受影响订阅 → 完成根因分析。

严重错误不得静默改字。页面显示更正时间、原错误性质和新证据。撤回不删除审计记录。

## 6. 时效

- 安全、隐私、错误选举结果：立即升级；
- 重大金额或政策错误：目标 4 小时内初步处置；
- 普通事实更正：目标 1 个工作日；
- 分类和别名问题：进入数据治理队列。

时效为运营目标，正式 SLA 需在上线前批准。
