# 数据合规、版权、隐私与保留政策

> 版本：v1.0-draft  
> 注意：本文件为产品与工程基线，不替代适用法域的专业法律意见。

## 1. 采集原则

只采集与明确产品目的相关的公开信息；优先 API、RSS、站点地图和正常公开访问；遵守网站条款、robots 和合理限速；不绕过登录、付费墙、验证码或访问控制。

## 2. 内容保存

- 法律允许且有证据需求时保存原始快照；
- 否则保存元数据、哈希、必要证据片段和原始链接；
- 公开网页默认展示事实、摘要和必要引用，不复制完整受保护文章；
- 图片、视频和 PDF 的公开再展示需单独评估权利；
- 来源删除不自动删除审计记录，但停止公开全文并标注不可访问。

## 3. 个人数据

只保存公共职责、企业角色、候选人和公开任职所必需的数据。普通个人的住址、证件、私人联系方式、家庭和非公开账号默认不采集。争议与指控进入高风险审核。

## 4. 数据层保留

| 层 | 默认策略 |
|---|---|
| L0 | 90 天后评估，只保留去重所需元数据 |
| L1 | 按来源权利和证据需要，默认 1 年复评 |
| L2 | 30–180 天复查，过期转 rejected/expired |
| L3 | 权威历史长期保留并版本化 |
| L4 | 随 L3 状态更新，撤回保留更正记录 |
| 隔离区 | 最短必要期限，仅授权访问 |

正式期限需依据法律审查、存储成本和业务需要批准，Agent 不直接不可恢复删除。

## 5. 请求处理

删除、更正、访问和版权投诉进入工单，验证申请人身份、定位受影响数据、暂停公开风险内容、记录决定，并向下游搜索、缓存和备份传播适用变更。

## 6. 第三方模型

发送数据前记录供应商、地区、保留设置和数据分类。隔离数据、密钥和非公开用户内容默认不得发送给外部模型。
