# 贸易指标首条数据闭环

> 版本：v1.0-draft  
> 数据集：`trade_sitc_1d`  
> 状态：本地闭环实现

## 1. 用户目标

公开首页提供马来西亚月度货物贸易的最新出口、进口、贸易差额、最近 12 个月总额和
SITC 一位数构成。页面只展示经过人工发布的 L4 投影；没有投影时显示治理空态。

## 2. 官方字段契约

来源为 data.gov.my 的 DOSM “Monthly Trade by SITC Section (1 digit)”数据集：

| 字段 | 语义 |
|---|---|
| `date` | 月份，格式 `YYYY-MM-01` |
| `section` | `overall` 或 SITC `0`–`9` |
| `exports` | 出口额，单位 RM million |
| `imports` | 进口额，单位 RM million |

最近两个月为暂定值，公开投影必须保留这一提示。来源许可为 CC BY 4.0。

## 3. 治理链路

```text
trial / active 来源采集
→ L2 原文与哈希留存
→ 人工完成 L2 接纳
→ Processing Agent 调用 Trade 领域服务
→ 校验官方字段并写入 canonical_private L3 批次
→ 确认最新月 10 个 SITC section 完整且有 12 个月 overall
→ Publisher 提交理由并创建不可覆盖的 L4 revision
→ GET /v1/trade/overview
→ Web 首页
```

`verification_hint=F4` 本身不能发布。首版只有同时满足已批准 L2、固定来源
`SRC-MY-DATAGOV`、S2、固定数据集和严格字段校验时，Verification 的
`official trade v1` 规则才赋予 F4。其他来源或数据集必须走新的验证规则。

## 4. 数据所有权

- `trade_indicator_batches`：Trade 模块拥有的 L3 标准化批次；
- `trade_indicator_observations`：批次内月度观测，不覆盖旧批次；
- `trade_indicator_publications`：Publisher 创建的版本化 L4 JSON 投影；
- PostgreSQL 是事实源，网页不得直接访问 data.gov.my；
- 公开 API 只读取唯一的 `is_current` 投影。

## 5. 发布门槛

- 来源、文档版本、采集 ID、哈希和抓取时间完整；
- L2 `processing_status=approved`；
- 规则解析后的数值有限且非负，月份必须是每月第一日；
- 最新月份包含 `overall` 和 section `0`–`9`；
- 至少有连续展示所需的 12 条 overall 月度观测；
- F4 规则通过；
- Publisher 身份、理由、幂等键、审计和 Outbox 同事务保存。

## 6. 明确限制

- 当前页面不把月度变化解释为产业因果或投资趋势；
- SITC 数据只覆盖货物贸易，不代表服务贸易；
- 试采的 10 条不满足完整发布门槛，只能保留在 L3 私有层作为验证证据；
- 生产环境在身份系统接入前拒绝 Processing 与 Publisher 写入；
- Agent 不得登记、批准来源、完成 L2 人工审核或模拟 Publisher。
