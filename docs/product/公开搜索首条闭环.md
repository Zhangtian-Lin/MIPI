# 公开搜索首条闭环

> 版本：v1.0-draft  
> 状态：本地事件搜索实现

## 1. 范围

首版搜索只读取 `event_publications.is_current=true` 的 L4 投影。可匹配中文标题、中文摘要、
公开证据原文以及来源名称；不读取 L2、L3、隔离数据、旧 revision、审计理由或原始全文。

搜索响应固定按 `events`、`companies`、`projects`、`policies`、`locations` 分组。当前只有
事件具备 L4 数据，因此其他分组返回空数组，而不是用候选数据填充。相应领域发布闭环完成后
可以在保持响应结构兼容的前提下逐组启用。

## 2. 匹配解释

每条事件结果返回一个主要命中原因和最多 240 字符的片段：中文标题、中文摘要、原文证据或
来源名称。标题优先于摘要，摘要优先于证据原文，证据原文优先于来源名。结果同时显示 F
等级、事件日期和详情入口，详情页继续承担完整证据核验。

## 3. 查询与安全

- 查询去除首尾空白并合并连续空白，长度为 2–100 字符；
- `%`、`_` 和反斜杠按字面量搜索，不允许用户改变 SQL 匹配语义；
- PostgreSQL 参数化查询，标题和摘要使用 trigram 索引；
- 结果页不允许搜索引擎索引任意查询 URL；
- API 故障时显示明确错误，不使用私有或缓存外数据兜底；
- 当前排序为匹配字段优先级，再按事件日期倒序，不宣称相关性算法已完成校准。

## 4. 明确限制

首版不是全站搜索：实体别名、企业、项目、政策和州属必须等各自 L4 View Model 上线后接入。
马来语词形变化、拼写纠错、中文分词、语义向量和跨语言召回尚未启用；这些能力需要黄金样本
评测，不能仅凭演示效果上线。
