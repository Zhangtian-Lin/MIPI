# 机器可执行契约规范

> 版本：v1.0-draft

## 1. 原则

Markdown 解释语义，JSON Schema/OpenAPI 执行校验。Schema 必须设置版本、禁止未知关键字段、使用稳定枚举并提供兼容策略。

## 2. 契约目录

```text
contracts/
├── ingestion-envelope.schema.json
├── document.schema.json
├── claim.schema.json
├── event.schema.json
├── verification.schema.json
├── review-task.schema.json
├── agent-run-report.schema.json
└── openapi.yaml
```

## 3. 兼容规则

- 新增可选字段属于次版本；
- 新增必填、删除字段、改变枚举含义属于主版本；
- 消费者必须安全处理未知非关键枚举；
- 破坏性变化提供双写、迁移、弃用期和回滚；
- 每个产物记录实际 contract version。

## 4. 校验顺序

语法校验 → Schema 校验 → 引用存在性 → 业务状态机 → 权限 → 幂等 → 写入。失败返回统一错误码和字段路径。
