# 来源注册与评级规范

> 版本：v1.1-draft

## 1. 注册流程

候选发现 → 身份验证 → 样本审查 → S 等级建议 → 访问与条款检查 → 人工批准 → 小流量试采 → 正式启用。

## 2. 必填字段

`source_id`、名称、所有者、域名或账号、S 等级、权威范围、语言、入口、更新频率、允许方式、限速、时区、日期规则、状态、最近评审时间。

## 3. 初始种子来源

## 4. 分级规则

S1 只授予相应事实类型的法定原始记录；同一域名的新闻稿仍可能是 S2。S3/S4 需检查署名、编辑、更正和原始报道能力。S5 必须验证账号归属。S6 只作为线索。

## 5. 复评

至少每 180 天复评，或在域名所有权变化、内容性质变化、长期停更、错误率异常、仿冒风险或更正机制失效时立即复评。

## 6. 来源生命周期

```text
candidate → trial → active
               └→ inactive → retired
active → degraded → active
   └──────────→ inactive
```

- `candidate`：只完成登记，不允许常规自动采集；
- `trial`：身份、条款、权威范围和 robots 已审核，只允许小流量试采；
- `active`：已有试采证据，可按来源计划运行；
- `degraded`：质量、解析或访问出现异常，仅允许受限重试和诊断；
- `inactive`：停止自动访问，可在重新核验并提供新证据后恢复；
- `retired`：终态，不得恢复；需要重新接入时创建新的来源治理流程。

状态决定不得改变 S 等级。S 等级回答“该来源对什么事实具有多强证明能力”，生命周期回答
“当前是否允许采集”。两者必须独立保存。

## 7. 试运行与激活门槛

`approve_for_trial` 必须同时确认：

- 来源主体身份已核验；
- 权威范围和语言字段非空并已审核；
- 访问条款已检查；
- robots 结论为 `allowed`、`limited` 或 `not_applicable`；
- `limited` 必须记录具体路径、频率或其他限制。

`activate` 只允许从 `trial`、`degraded` 或 `inactive` 进入 `active`，并且至少提交一个
实际试采或复核证据 URL。`unknown` 或 `disallowed` 的访问状态不能获准自动采集。

每次决定写入不可覆盖的 `source_decisions`，保存前后状态、审核人、角色、理由、规则版本、
robots 结论、证据 URL 和访问说明。试运行、激活和降级来源的下一次常规复评时间为决定后
180 天；异常触发复评不受该日期限制。

本地环境可以使用测试 `source_admin` 身份验证流程；测试、预发布和生产环境在接入真实身份
提供方之前拒绝来源写操作。

来源决定必须携带 `Idempotency-Key`。相同键和相同决定返回原决定 ID 与当前来源快照；相同
键对应不同内容时返回 409，管理员不得通过更换请求内容复用旧键。
