# 分类体系与术语规范

> 版本：v1.0-draft

## 1. 产业树

```text
data_ai_infrastructure
├── data_center
├── cloud
├── ai_compute
├── network_connectivity
└── supporting_energy_water

semiconductor
├── design
├── wafer_fabrication
├── assembly_test
├── equipment
└── materials

advanced_manufacturing_energy
├── automation_robotics
├── electronics
├── solar
├── battery
├── electric_vehicle
└── industrial_energy
```

## 2. 事件类型

`investment`、`project_announcement`、`approval`、`incentive`、`construction`、`operation_start`、`delay`、`suspension`、`cancellation`、`partnership`、`policy_publish`、`policy_amend`、`tender`、`financial_disclosure`、`election_result`、`office_change`。

## 3. 地理层级

`country → state/federal_territory → district → city → industrial_park → site`；选区作为带版本的平行层：`parliamentary_constituency`、`state_constituency`。

## 4. 多语言术语

词典每条包含 `concept_id`、中文、英语、马来语、别名、禁用误译、适用范围和审核状态。首批必须覆盖投资、项目状态、政策、选举、政府职务、金额单位和三个产业。

## 5. 新分类流程

无法分类的数据进入 L2，并标记 `taxonomy_review`。新概念需提供至少三个真实样本、与现有分类的区别、父节点、跨语言名称、迁移影响和批准人。

## 6. 禁止行为

- 不创建“其他”作为长期垃圾桶；
- 不用媒体栏目直接代替领域分类；
- 不把州、城市、园区混为一个地点；
- 不把企业宣传词直接变成标准产业名；
- 不在未迁移历史数据前改变枚举语义。
