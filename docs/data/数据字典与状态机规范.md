# 数据字典与状态机规范

> 版本：v1.0-draft

## 1. 通用约定

- 内部主键使用 UUID；公开 ID 使用稳定前缀，如 `DOC-`、`EVT-`、`ENT-`；
- 时间使用带时区 ISO 8601，数据库统一存 UTC，显示按用户时区；
- `0`、`null`、`unknown`、`not_disclosed`、`not_applicable` 语义不同；
- 金额保存 `amount_original`、`currency`、`amount_min/max`、`amount_basis`；
- 所有可变关系支持 `valid_from`、`valid_to`、`observed_at`；
- 权威事实只追加版本，不静默覆盖。

## 2. 核心对象

| 对象 | 必需字段 |
|---|---|
| Source | id、name、owner、grade、authority_scope、status |
| Document | id、source_id、canonical_url、type、language、published_at、hash |
| DocumentVersion | id、document_id、raw_uri、text、crawled_at、previous_version_id |
| Entity | id、type、canonical_name、names、status |
| Claim | id、subject、predicate、value、value_type、status |
| Evidence | claim_id、document_version_id、source_span、role、directness |
| Event | id、type、event_date、status、summary、verification |
| Project | id、name、industry、location、status、status_as_of |
| Policy | id、name、issuer、level、current_version_id、status |
| Election | id、type、jurisdiction、date、result_status |

## 3. 文档状态机

```text
discovered → fetched → parsed → processed → reviewed → canonical
      └→ failed → retrying → dead_letter
      └→ quarantined
```

只有 `reviewed/canonical` 可修改 L3；`quarantined` 仅授权人员可见。

## 4. 发布状态机

```text
discovered → raw_only → staged → under_review
→ canonical_private → publishable → published
                         ├→ rejected
                         ├→ expired
                         └→ quarantined
```

## 5. 项目状态机

```text
rumor → intent → announced → approved → construction
→ trial_operation → operational
任一阶段可进入 delayed / scaled_down / suspended / cancelled
```

状态必须有 `status_evidence_claim_id` 和 `status_as_of`。企业宣布不能自动推进到 operational。

## 6. 政策状态机

```text
draft → announced → gazetted → effective → amended → expired/repealed
```

`announced` 不等于 `effective`；每个版本分别保存发布时间、生效时间和替代关系。

## 7. 事实验证

F0 线索、F1 单一来源、F2 第一方宣布、F3 多独立来源一致、F4 权威记录确认。附加状态包括 partial、conflict、corrected、retracted、superseded、source_unavailable。

F 等级变化必须记录依据、规则版本、操作者和时间。降级与撤回同样需要审计。

## 8. Evidence role

- `supports`；
- `contradicts`；
- `mentions`；
- `supersedes`；
- `retracts`。

## 9. 空值规范

| 值 | 含义 |
|---|---|
| `null` | 尚未处理或值不存在 |
| `unknown` | 已检查但无法确认 |
| `not_disclosed` | 来源明确未披露 |
| `not_applicable` | 字段不适用 |
| `0` | 已确认数值为零 |
