# 品牌、设计系统与页面原型规范

> 版本：v1.0-draft

## 1. 品牌语气

准确、克制、专业、可验证。避免夸张新闻标题、政治标签和无依据趋势断言。默认中文，保留原文名称和术语。

## 2. 视觉语义

设计 Token 使用业务名称：`fact.confirmed`、`fact.partial`、`fact.conflict`、`fact.unverified`、`source.official`、`source.media`、`source.social`。颜色不是唯一信号，必须配合文字和图标。

## 3. 栅格与断点

移动 360–430、平板、桌面和宽屏分别验收；主体设最大宽度；桌面侧栏在移动端转为折叠或底部 Sheet。

## 4. 核心组件状态

每个组件覆盖 default、hover、focus、loading、empty、partial、conflict、error、disabled、stale。长中英文名称、超长金额和无图片均需测试。

## 5. P0 页面原型要求

首页、变化、事件、产业、州属、企业、项目、政策、搜索和方法论必须分别提供手机和桌面线框。每个线框标明首屏目标、数据接口、组件、空态、证据入口和移动替代。

## 6. 关键交互

- Evidence Drawer：焦点管理、原文高亮和外链；
- Policy Diff：桌面表格、移动变化卡；
- Filter：URL 可分享，移动全屏面板；
- Timeline：区分事件日与确认日；
- Conflict Notice：当前值、其他口径和理由；
- Map：提供等价列表和数据说明。

## 7. 可访问性

键盘完整操作、明显焦点、语义标题、表单标签、图表文字摘要、Dialog 焦点圈、减少动画和足够对比度。目标遵循适用的 WCAG AA 基线。

## 8. 原型验收

信息职责与 IA 一致；关键事实可下钻；S/F 状态不弱化；无真实数据时明确 Mock；手机无横向溢出；页面截图进入视觉回归基线。
